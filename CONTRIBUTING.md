# Contributing

Before publishing, the maintainer must choose a license and contribution terms. Keep each skill focused, describe when it is used, identify trust boundaries and provide concrete adversarial and valid-use tests. Do not invent engine APIs or claim tests ran when they did not. Verify version-dependent advice against official documentation. Update the router and marketplace for new skills, run `python scripts/validate.py` and `python -m unittest discover -s tests -v`, and explain security tradeoffs in review.
